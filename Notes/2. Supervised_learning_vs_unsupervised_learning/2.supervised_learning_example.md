### Data

The data is split to a **training data set** and a **test data set** the training set has labels, so your model can learn from these labeled examples.

the test set does not have models, i.e. you don't yet know the value you're trying to predict.


it's important that your mdoel can generalize to situations it hasn't encountered before so that it can perform well on the test data.
